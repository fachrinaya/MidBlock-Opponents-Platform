# What to expect — section prompt

Write the “What to expect” briefing in English, addressing the player as “you”. Synthesise the strongest match-preparation priorities from the supplied evidence and prior sections. Lead with the team threat and the player's responsibilities. Give a small number of concrete actions that can be remembered before kick-off.

Use a measured working read for the opponent's approach, then name the relevant delivery or goal threats. Explain the response in normal football language: protect an inside passing lane, press with teammate cover, stop a delivery, scan a receiver, or combine with a supporting full-back. Select only actions justified by the supplied report and express them as a proposed plan. Do not introduce a new metric, tactical system, player attribute or predicted result.

Do not repeat the full tables or turn the briefing into a methods summary. Keep coverage explanations in About unless omitting one would make a specific number misleading. Write one connected paragraph rather than a checklist. Return the `verdict` field only.

## Evidence and writing rules

- Use only the supplied records for player/team facts. Nutmeg references supply methodology, not opponent evidence.
- Distinguish observed contribution, working scouting read, and proposed player response.
- Missing values remain unknown. Preserve cutoff, match windows, metric units, sample sizes and model scores.
- Per90 means per 90 minutes; a percentile is a peer rank, not an action success rate.
- Do not infer a press, high line, man marking, physical trait, specific off-ball run or causal weakness from aggregates or average locations.
- Keep routine method caveats in About while making every specific observation accurate.
- Return only the section's required JSON fields. References and player/chart identities must match the supplied inputs.
